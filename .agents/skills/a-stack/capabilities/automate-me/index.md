# Automate me

Draft or update a personal mode from repeated behavior in scoped task history.

1. Read recent history for the active workspace through `history.read`. For a
   global personal mode, ask before broadening beyond the active workspace.
2. Partition history into several time slices and delegate reduction. Look for
   repeated preferences in intent, explanation, planning, delegation, code,
   verification, review, prose, and handoff.
3. Require support from at least two independent history slices before calling a
   pattern durable. Keep contradictions visible.
4. Ask the user only about disputed identity-level preferences. Do not make one
   task's constraint part of their personality.
5. Draft or update the mode through the provider skill-authoring capability.
   Keep one source of truth per rule and route branch-specific detail behind
   references.
6. Apply Unslop, validate the skill, and present the draft for subjective review.
7. Publish only when the user authorizes the required repository actions.

**Reply:** evidence slices, accepted preferences, contradictions, draft path,
validation, and publication state.
